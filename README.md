# 宝石消消乐

一个在浏览器里直接打开就能玩的三消益智游戏，风格接近宝石迷阵 / Candy Crush。无需安装依赖，也没有构建步骤。

## 怎么开始

用浏览器打开项目根目录的 `index.html` 即可开始。

也可以在项目目录启动一个静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

部署到 GitHub Pages 时，把站点目录设为仓库根目录即可，入口文件是 `index.html`。

## 怎么玩

- 棋盘为 8×8，共有 6 种宝石（不同颜色和形状）。开局不会自带可消除的连线。
- **点击**一颗宝石，再点击相邻的一颗，即可交换。也可以**按住拖动或滑动**到相邻格（鼠标和触摸都可以）。
- 横排或竖排连成 **3 个及以上**相同宝石就会消除。宝石下落，空位从顶部补充。若因此又形成连线，会继续连锁。
- 不能形成消除的交换会动画换回，**不消耗步数**。
- 本局共 **30 步**。步数用完后游戏结束，可点「重新开始」或「再来一局」。
- 如果棋盘上没有任何可消除的走法，会自动重新排列宝石。
- 停手大约 8 秒后，一对可以交换的宝石会闪烁提示。

## 计分

- 每条连线得分为：宝石数 × 10。
- 四连额外 +30 分，五连及以上额外 +80 分。
- 十字形或 L 形会按横、竖两条连线分别计分。
- 同一次交换引发的第 n 波连锁，该波得分 × n。

最高分会保存在本机浏览器中。

## 运行测试

消除检测、重力、补块和连锁放在 `js/logic.js`，与页面渲染（`js/ui.js`）分开，可用 Node 自带测试运行器验证：

```bash
node --test tests/logic.test.js
```

或：

```bash
npm test
```

## 项目结构

- `index.html`：页面
- `css/style.css`：布局与动画
- `js/logic.js`：纯游戏规则
- `js/ui.js`：渲染、动画与操作
- `tests/logic.test.js`：规则单元测试

现代浏览器（Chrome、Edge、Firefox、Safari）均可游玩。
